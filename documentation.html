Technical Documentation

How the pipeline is organized, how to reproduce every result on this site, and what each script does.

Source files

FileRole
src/uav_fl_project.pyFull pipeline: cleaning, baselines, federated learning, autoencoder, continual learning, explainability
src/uav_fl_hybrid_model_v3.pyHybrid AE-Stacked Ensemble, 3-class
src/uav_fl_hybrid_model_binary.pyHybrid AE-Stacked Ensemble, binary — the final proposed model

Reproducing the results

pip install -r requirements.txt

# Full pipeline: baselines + federated learning + autoencoder + continual learning + explainability
python src/uav_fl_project.py --data data/Dataset_T-ITS.csv --output results/full_run

# Final proposed model (binary hybrid)
python src/uav_fl_hybrid_model_binary.py --data data/Dataset_T-ITS.csv --output results/binary_run

Or open notebooks/UAV_FL_Hybrid_Binary_Model.ipynb and run all cells — no other setup required.

Federated learning configuration

ParameterValue
Clients8 simulated UAVs
Clusters2
Rounds5
PartitioningDirichlet(α = 0.30), severe non-IID

Explainability method

SHAP was designed into the pipeline; the SHAP package was unavailable in the evaluation environment, so the system automatically fell back to permutation importance rather than silently skipping explainability. This is reported honestly in run_summary.json as "xai_method": "Permutation fallback (ModuleNotFoundError)".

Deployment

This site is a static HTML/CSS/JS build (Chart.js loaded from CDN) — no build step. Deployed on Vercel with site/ as the project root directory.
