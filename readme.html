Project Overview

SEAQL — Scalable, Explainable, and Adaptive Quantum-Resilient Federated Learning for UAV Swarm Cybersecurity

A hybrid, federated, and explainable intrusion-detection framework for UAV swarm networks, evaluated end-to-end on a real packet-capture dataset. Final model: 94.3% accuracy / 93.3% macro F1-score / 98.3% AUC on binary attack detection.

Research Problem

UAV swarms coordinate over shared wireless links, exposing them to Denial-of-Service flooding and packet Replay attacks. Existing UAV intrusion-detection research is typically centralized, non-explainable, and static once deployed.

Methodology

  • Data cleaning: type coercion, identifier removal, duplicate removal → 32 usable features
  • Stratified 60/20/20 train/validation/test split
  • Baseline models: Logistic Regression, MLP, Random Forest
  • Hierarchical Federated Learning: 8 simulated clients, 2 clusters, non-IID partitioning
  • Autoencoder anomaly detector, trained on benign traffic only
  • Hybrid AE-Stacked Ensemble: autoencoder features + 5-model stack (RF, XGBoost, LightGBM, Extra Trees, MLP)
  • Final model reframed for binary attack-vs-benign detection

Results Summary

Baseline Random Forest reached 73.4% macro F1 on the 3-class task. The proposed hybrid model reached 74.4% on the same 3-class task, and 93.3% macro F1 (94.3% accuracy) once reframed for binary attack detection — after three independent architectures confirmed that DoS/Replay confusion is a data-level property, not a modeling weakness.

Repository Structure
